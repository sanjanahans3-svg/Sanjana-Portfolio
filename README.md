# Sanjana Hans — Academic Portfolio

A polished React portfolio for Sanjana Hans covering academics, teaching, research/review publication, credentials and academic entrepreneurship.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Add passport-size photo

The Home page currently shows a clean placeholder because no passport-size photo was supplied in the source files.

When the photo is available, add it as:

`src/Assets/profile-photo.jpg`

and replace the placeholder in `src/components/Home/Home.js` with the image.

## Included documents

- `public/sanjana-cv.pdf` — CV
- `public/research/prostate-cancer-biomarkers.pdf` — published review paper
- `src/Assets/Certificates/` — supplied certificate photographs

## Hosting

This is a Create React App project. It can be hosted on GitHub Pages or another static hosting service after running `npm run build`.
